# Lab 27：嵌套集合的扁平化与稳定资源键

## 任务

`team_apps` 按团队组织应用：每个团队有自己的标签和应用列表。

在 `starter/main.tf` 中，将这份嵌套配置展开为“每个应用一条记录”，再为每条记录创建 `terraform_data.app`。资源和输出的键必须同时包含团队名与应用名，例如 `platform.api`，这样不同团队中的同名应用仍是两个独立对象。

标签按“全局 → 团队 → 应用”的顺序合并；越具体的标签优先级越高。空团队不产生记录；同一团队内出现重复应用名时，仍应拒绝输入。

## 约束

- 使用 `flatten` 和 `merge` 推导结果，不要手工写死应用。
- 不要用列表下标作为资源身份。
- 只能编辑 `starter/main.tf`。
