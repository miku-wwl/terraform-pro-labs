# Lab 21：使用动态块生成 Security Group 入站规则

## 任务

`ingress_rules` 是一组入站规则，每条规则包含描述、端口和 CIDR。将现有重复的静态 `ingress` 块改为由这组输入动态生成的嵌套块。

生成的每条入站规则都要保留自己的描述、端口与 CIDR；端口范围从该端口到同一个端口，协议为 TCP。输入规则数量变化时，生成的 `ingress` 块数量和内容也必须随之变化。

固定的全协议 IPv4 出站规则保持不变，端口校验也保持有效。

## 约束

- 只维护一个 Security Group 资源。
- 不保留静态 `ingress` 块。
- 不硬编码测试中替换的规则值。
- 不编辑测试文件。
- 只能编辑 `starter/main.tf`。
