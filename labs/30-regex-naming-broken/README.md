# Lab 30：正则命名校验与规范化

## 任务

在 `starter/main.tf` 中完善 `project_name` 的命名规则：长度只能是 3～24 个字符，必须以字母开头、以字母或数字结尾，中间只允许字母、数字、下划线和连字符。

通过校验后，将名称转为小写；连续出现的下划线或连字符要合并成一个连字符。例如 `Payments__--API` 应得到 `payments-api`。后续的词元拆分与 `-${environment}` 后缀都必须基于规范化后的名称。

`environment` 的现有校验保持不变。

## 约束

- 用正则表达式定义命名规则，不要针对测试值逐个判断。
- 不要硬编码输出结果。
- 只能编辑 `starter/main.tf`。
