# Terraform Professional Practice Labs

This repository is being converted into a deterministic, resettable starter collection. The
current executable pilot set is Labs 01, 07, 11, 25, and 31; the remaining labs are retained as
legacy migration inputs and are not executed by the aggregate gate.

From the repository root:

```text
python tools/labctl.py list
python tools/labctl.py check --all
```

Use each pilot README for its editable files, expected starter failure, solution criteria, and
reset workflow. Default pilot validation requires no cloud credentials and creates no billable
resources.
